# ☕ Moderation Panel — Java Discord V2 Bot API Service

Bu servis, **Java SE 8+** altyapısı üzerine inşa edilmiş **Java Discord Components V2** duyuru ve bot yönetim servisidir.

---

### 📂 Proje Dosyaları:

- **`java-backend/DiscordV2Bot.java`**: Java SE HTTP Server tabanlı Discord V2 Bot & API Servisi
- **`java-backend/pom.xml`**: Java Maven bağımlılıkları (JDA — Java Discord API v5)

---

### 🚀 Çalıştırma Talimatı:

1. Komut satırında `java-backend` klasörüne girin:
   ```bash
   cd java-backend
   ```
2. Java servisini derleyip çalıştırın:
   ```bash
   javac com/milky/moderation/DiscordV2Bot.java
   java com.milky.moderation.DiscordV2Bot
   ```
3. Servis `http://localhost:8080/api/announce` adresi üzerinden canlıya geçecektir!
